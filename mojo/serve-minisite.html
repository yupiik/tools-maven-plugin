yupiik-tools:serve-minisite

Minisite goa with HTTP server.

Coordinates

<plugin>
  <groupId>io.yupiik.maven</groupId>
  <artifactId>yupiik-tools-maven-plugin</artifactId>
  <version>1.3.1-SNAPSHOT</version>
</plugin>

To call this goal from the command line execute: mvn yupiik-tools:serve-minisite.

To bind this goal in the build you can use: 

<plugin>
  <groupId>io.yupiik.maven</groupId>
  <artifactId>yupiik-tools-maven-plugin</artifactId>
  <version>1.3.1-SNAPSHOT</version>
  <executions>
    <execution>
      <id>my-execution</id>
      <goals>
        <goal>serve-minisite</goal>
      </goals>
      <configuration>
        <!-- execution specific configuration come there -->
      </configuration>
    </execution>
  </executions>
</plugin>

You can execute this goal particularly with mvn yupiik-tools:serve-minisite@my-execution command.

llmChatEnabled (boolean)

Enable LLM-powered chat on the site: a fully in-browser, retrieval-augmented (RAG) assistant over the generated documentation (no backend, no API key). At build time the documentation is chunked and embedded with all-MiniLM-L6-v2; at runtime the browser embeds the question with the same model and a local WebLLM model (llmModelId) answers using the retrieved chunks. See Minisite LLM Chat for the build-time setup and a description of the underlying mechanism.

Requires the langchain4j-embeddings-all-minilm-l6-v2 dependency to be added as a plugin dependency (it ships the embedding model used at build time); the build fails fast if it is missing: <dependency> <groupId>dev.langchain4j</groupId> <artifactId>langchain4j-embeddings-all-minilm-l6-v2</artifactId> <version>1.16.1-beta26</version> </dependency> See also: Minisite LLM Chat documentation < https://yupiik.io/tools-maven-plugin/minisite-llm.html> . Default value: false. Property: ${yupiik.minisite.llmChatEnabled}.

llmModelId (String)

WebLLM model identifier for the chat. Default value: Llama-3.2-3B-Instruct-q4f16_1-MLC. Property: ${yupiik.minisite.llmModelId}.
